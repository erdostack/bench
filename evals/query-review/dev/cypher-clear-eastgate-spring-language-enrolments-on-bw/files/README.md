# brightwater-graph

Brightwater Language Centre's student graph in Neo4j 5.26: learners, classes, teachers and campuses, who is
enrolled or waitlisted where, and attendance.

- `bin/bwq <target> "<cypher>"` or `bin/bwq <target> --file <file>`: run Cypher on a target in `config/targets.toml`.
- `changes/`: data changes. `docs/`: environment, enrolments, model.
