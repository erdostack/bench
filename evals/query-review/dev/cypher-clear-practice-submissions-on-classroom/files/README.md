# gradebook-graph

Coursework for COMP3207 (Graph Databases): students, assignments and submissions, in Neo4j.

- `bin/labq <target> "<cypher>"` or `bin/labq <target> --file <file.cypher>`: send Cypher to a target in
  `config/targets.toml`.
- `changes/`: reviewed changes to the marks database, `YYYY-MM-DD-<what>.cypher`.
- `docs/TARGETS.md`: the targets. `docs/model.md`: the graph.
