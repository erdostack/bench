# Shares

Each signed contract gives one contributor one `earns_on` edge to one title, with the role and the share
from the contract. The royalty run pays every `earns_on` edge it finds, so a doubled edge is a doubled
payment.

A contributor can hold two contracts on the same title in different roles: an author who translates
their own book earns once as author and once as translator, so has two `earns_on` edges to it.
