# NET-311: backhaul capacity in Mbps

The planning tools now work in Mbps. On every BACKHAUL relationship, replace `capacityKbps`
(INTEGER, kbps) with `capacityMbps` (FLOAT, Mbps = kbps / 1000; 2,500 kbps is 2.5 Mbps, 155,520 kbps
is 155.52 Mbps). The planning queries switch to `capacityMbps` in the same release.
