# guildgraph

The guild graph of Emberfall: players, guilds, memberships, invites and join requests. Neo4j 5.26.

- `bin/gx live "<cypher>"` or `bin/gx live --file <file>`: run Cypher on the graph.
- `changes/NNNN-<what>.cypher`: reviewed data changes.
- `docs/graph.md`: the model. `docs/operating.md`: how the graph is run and changed.
