# Catalogue rules

- Codes are unique. A retired code is never reused.
- Prerequisites form an acyclic graph; registration refuses any course that cannot be reached by
  passing courses in some order.
- A course lists each prerequisite once, with one minimum grade. Grades from weakest to strictest:
  D, C-, C, B-, B. When two departments' lists for a course are combined, the stricter grade stands.
- Labs (`... L`) were separate courses until 2026; most of them list their lecture as a prerequisite.
