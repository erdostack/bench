# pedalshare-graph

Bike-share graph (Neo4j 5.26 LTS): riders, rides, docks, payment cards and invoices.

- `cypher/app/`: what the rider app runs.
- `cypher/privacy/`: statements the privacy team runs by hand, one rider at a time.
- `docs/model.md`: labels and relationships.
- `docs/privacy/retention.md`: what is kept, for how long, and what an erasure does (owned by the DPO's
  office, last reviewed 2026-06-02).
