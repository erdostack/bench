# The network

Nodes carry `kind` (`centre`, `lab`, `depot`, `hospital`) and `name`. Hospital codes are `H-` plus three
letters (`H-QMR`); places added by trainers for an exercise use `TEST-` codes. An edge is a road route with
`minutes` (drive time) and `road` (`A`, `B`, `M` for motorway). The graph is undirected.
