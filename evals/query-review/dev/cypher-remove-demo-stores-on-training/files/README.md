# storeops

Store operations graph: stores, the regions they sit in, who works where, and what each store ranges.

- `bin/tq <server> "<cypher>"` or `bin/tq <server> --file <file>`: run Cypher on a server from `config/servers.toml`.
- `changes/`: reviewed data changes for estate, `NNNN_<slug>.cypher`.
- `course/`: material for the store-setup course that runs on the training server.
- `docs/`: servers, the model.
