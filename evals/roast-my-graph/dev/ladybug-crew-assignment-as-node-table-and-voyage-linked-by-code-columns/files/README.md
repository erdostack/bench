# fleetlog

Crew and voyage history for a ferry operator. The database is LadybugDB, embedded in the ops desktop tool.

    graph/schema.cypher    table definitions
    graph/queries.cypher   queries the tool runs (named with `// name:`)

Roughly 4,000 sailors, 60 vessels, 140 ports, 22,000 crew assignments and 900,000 voyages going back to 2009.
