# parcelhub

Tracking backend for a courier co-operative. Spring Boot, JPA, PostgreSQL.

    docker compose up -d
    ./mvnw spring-boot:run

## Roadmap

- Q1: proof-of-delivery photos
- Q2: customer notification preferences
- Later: evaluate a graph database (probably Neo4j) for hub-to-hub route suggestions; see
  `docs/ideas/graph-routing.md`
