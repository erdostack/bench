# Teaching notes

Week 3 exercise: ask who is stranded if the limpet disappears from the pool (`/stranded?species=limpet`), then
compare with the dog whelk. Students predict first and run the query second.

The property type constraint on `trophic_level` is part of the exercise in week 5 (students try to store "3" as
text and see it refused), which is why the stack runs an edition that supports it.
