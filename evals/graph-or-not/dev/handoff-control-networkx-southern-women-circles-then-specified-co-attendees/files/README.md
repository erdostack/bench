# circles

Small web pages for the history society's exhibit on the 1930s "Southern Women" study of who attended which
social events. The attendance list is in `data/attendance.csv` (one row per woman and event; generated by
`setup.py` from the copy bundled with networkx).

- `society/data.py`: reading the attendance list.
- `society/pages.py`: the exhibit pages.

    pip install -r requirements.txt
