# ADR 0003: sign-off chain

Status: accepted, 2026-11-24

Decision: in-process-library

Context: 6,400 employees, 7,900 reporting lines (1,500 dotted), chains up to 12 levels. Finance: only solid lines
count; the chain starts at the submitter's manager and ends with the first person at grade 7 or above. The export
has 23 loops; a person already in the chain, or the submitter, ends it.
